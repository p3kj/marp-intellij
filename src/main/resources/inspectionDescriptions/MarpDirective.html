Reports directive comments and the front matter of a Marp deck that Marp ignores or misreads: a directive name that does not exist, a global directive written with an underscore, and an invalid value for paginate, math or headingDivider.

Marp drops such a directive without a hint, and the slide just looks wrong.

<!-- _theme: gaia -->
<!-- _clas: lead -->
<!-- paginate: yes -->

The same checks apply to the front matter:

---
marp: true
pagiante: true
paginate: true # on
---

The front matter also holds metadata of other tools (title, author and so on), so a key in it is only reported when it is a near miss of a directive, as a weak warning. Short names are only reported when they differ from the directive in case (Size), because words such as path or site are ordinary keys.

Unknown theme names are not reported here, the preview page shows a warning for them.
